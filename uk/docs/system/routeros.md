# Mikrotik RouterOS

!!! abstract "Огляд"

    Для маршрутизаторів Mikrotik з RouterOS WildcoreDMS працює через **API RouterOS** і показує
    окрему сторінку з інтерфейсами, адресними списками, ARP, DHCP, чергами та BGP-сесіями.
    Комутатори Mikrotik CRS/SwOS працюють як [звичайні комутатори](./switches.md).

!!! info "Компонент"
    [Mikrotik RouterOS](../components/router_os.md) (`router_os`).

## Підключення { #connection }

- Потрібен доступ до API RouterOS: сервіс `api` на маршрутизаторі увімкнено і дозволено з адреси
  сервера WildcoreDMS.
- Логін і пароль беруться з [доступу](../management/device-access.md) пристрою.
- Порт API за замовчуванням — `8728`. Змінити: для всієї системи — `SWC_MIKROTIK_API_PORT` у
  [Налаштуваннях системи](../installation-and-updating/env-configuration.md#swc), для моделі чи
  пристрою — ключ `mikrotik_api_port` у [додаткових параметрах](../management/custom-parameters.md#sw_core_connection).

## Вкладки

| Вкладка | Що показує |
|---------|------------|
| **Інтерфейси** | Назва, тип, статус (up/down/disabled), час останнього підняття лінка, кількість падінь, трафік та лічильники |
| **Список адрес** | Address lists фаєрвола: назва списку, адреса, чи динамічний/вимкнений запис, час створення |
| **ARPs** | IP, MAC, інтерфейс (VLAN), статус, коментар |
| **Оренда** | DHCP leases: IP, MAC, hostname, DHCP-сервер, статус, час оренди та закінчення, остання активність |
| **DHCP серверів** | Сервери: назва, інтерфейс, пул адрес, час оренди |
| **Прості черги** | Simple queues: назва, ціль (IP), limit-at, max-limit, тип, динамічна/вимкнена |
| **Сесії BGP** | Назва, локальна та віддалена адреса, віддалена AS, статус, аптайм |

Дані оновлюються кнопкою оновлення вкладки. Історія трафіку інтерфейсів збирається
[опитувачем](./poller.md).

!!! info "Права"
