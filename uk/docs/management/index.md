# Керування: огляд

!!! abstract "Огляд"

    Розділи меню **«Керування пристроями»** та **«Користувачі»** — це місце, де адміністратор
    описує мережу для WildcoreDMS (як підключатися до обладнання, які пристрої опитувати,
    як їх групувати) і хто та що може в системі робити.

| Меню | Сторінка | Для чого |
|------|----------|----------|
| Керування пристроями → **Доступи** | [Доступи до обладнання](./device-access.md) | SNMP community, логін/пароль консолі, порти та тайм-аути |
| Керування пристроями → **Пристрої** | [Пристрої](./devices.md) | додавання, редагування та вимкнення обладнання |
| Керування пристроями → **Групи** | [Групи пристроїв](./device-groups.md) | об'єднання пристроїв і обмеження видимості для користувачів |
| Керування пристроями → **Моделі** | [Моделі обладнання](./device-models.md) | опитувачі та додаткові параметри для всіх пристроїв моделі |
| Користувачі → **Користувачі** | [Користувачі](./users.md) | облікові записи, роль, групи пристроїв, статус |
| Користувачі → **Ролі** | [Ролі та права](./roles.md) | набори прав, які призначаються користувачам |

## Порядок початкового налаштування

1. Створіть **доступ** з SNMP community та обліковими даними консолі вашого обладнання.
2. Створіть **групи** пристроїв (наприклад, за районами або типами обладнання).
3. Додайте **пристрої**: IP, доступ, група — модель WildcoreDMS визначить сам.
4. Створіть **ролі** (наприклад «Оператор», «Монтажник») з потрібними правами.
5. Створіть **користувачів**, призначте їм роль і групи пристроїв.

!!! info "Хто бачить ці розділи"
    Пункти меню показуються лише користувачам з відповідними правами: «Керування пристроями»,
    «Керування доступом до пристроїв», «Керування групами пристроїв» та «Повний доступ до
    управління користувачами». Див. [Ролі та права](./roles.md).
