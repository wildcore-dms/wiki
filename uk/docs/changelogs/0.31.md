# Версія 0.31
_Дата релізу: 2026-09-28_

### Вхід через SSO (OpenID Connect) 🔐
- **Єдиний вхід через корпоративного провайдера.** Додано вхід у WildcoreDMS через будь-якого провайдера OpenID Connect: Keycloak, Authentik, Google Workspace, Microsoft Entra ID (Azure AD), Auth0, Authelia тощо. На сторінці входу з'являється кнопка **«Увійти через ...»** з назвою, яку ви задаєте самі.
- **Автоматичне створення користувачів.** При першому вході наявний користувач знаходиться за email або логіном і прив'язується до облікового запису провайдера; якщо його немає — створюється автоматично.
- **Ролі за групами провайдера.** У налаштуваннях ролі з'явилось поле **«Зіставлення груп SSO»**: користувачі з вказаних груп/ролей провайдера автоматично отримують цю роль. Роль може перераховуватись при кожному вході або призначатись лише один раз. Для провайдерів без груп (Google) — роль за замовчуванням.
- **Гнучкі способи входу.** Можна залишити вхід за паролем паралельно з SSO, залишити лише SSO (з автоматичним переходом на сторінку провайдера) або заборонити вхід за паролем користувачам, створеним через SSO. Двофакторна автентифікація та обмеження за IP діють і для SSO.
- **Майстер налаштування.** Команда `wca auth:configure` покроково налаштовує SSO, перевіряє доступність провайдера, виводить redirect URI, підказки для обраного провайдера та допомагає зіставити ролі. Для Keycloak генерує файл для імпорту, який одразу створює клієнт, mapper та ролі.
- У картці користувача та в параметрах аккаунту з'явилось поле **Email** (використовується для прив'язки до SSO).
- Інструкції: [Вхід через SSO](../sso/index.md), покроково для [Keycloak](../sso/keycloak.md), [Authentik](../sso/authentik.md), [Google Workspace](../sso/google.md), [Microsoft Entra ID](../sso/entra-id.md), [Auth0](../sso/auth0.md).

### Темна тема та оформлення 🌙
- **Темна тема.** Веб-панель отримала темну тему. Перемикач — у меню користувача (іконка профілю у правому верхньому куті) → **«Темна тема» / «Світла тема»**; доступний і в мобільній версії. Вибір запам'ятовується у браузері, одразу застосовується у всіх відкритих вкладках і не дає «спалаху» світлої теми при завантаженні.
- У темній темі адаптовано таблиці, календарі, топологію, карту, консоль, журнали подій, блоки портів і діагностики кабелю, статуси ONU, графіки та віджети дешборду.
- **Оновлене оформлення.** Єдині кольори, відступи та пагінація на всіх сторінках, оновлені бокове меню, верхня панель, «хлібні крихти» та сторінка входу; компактніші таблиці та пагінація.
- **Підказки до полів.** На картках пристроїв, OLT та ONU з'явились підказки «?» з поясненням кожного поля. Їх можна вимкнути перемикачем **«Вимкнути підказки»** у параметрах аккаунту.
- Довгі рядки вкладок (пристрій, OLT, макроси, реєстрація ONU, налаштування системи, події, сповіщення) прокручуються колесом миші, на сторінках OLT — ще й кнопками-стрілками.
- Довгі модальні вікна прокручуються всередині, а не виходять за межі екрана.
- Швидше початкове завантаження веб-панелі — сторінки підвантажуються за потреби.
- Прибрано застаріле спливаюче повідомлення про невідповідність версії агента.

### PWA та стабільність веб-панелі 📱
- Виправлено «вічне завантаження» встановленого застосунку (PWA): нова версія підхоплюється одразу після оновлення, а кеш використовується лише як резерв без мережі.
- Застосунок сам перевіряє наявність нової версії (при поверненні у вікно, відновленні зв'язку та кожні 30 хвилин) і оновлюється.
- Виправлено відкриття веб-консолі у встановленому застосунку та іконку застосунку.

### ONU та OLT 📡
- **Історія рівнів сигналу ONU.** Система запам'ятовує мінімальний і максимальний рівень RX (з боку ONU та з боку OLT), час останньої зміни та відхилення від поточного значення. Межі можна скинути кнопкою **«Скинути граничні рівні сигналів»** (блок «Історичні межі сигналу»).
- **Список ONU:** нова колонка **«Оптичний RX delta»** (зміна сигналу) з сортуванням, сортування за RX з боку OLT, знову працює фільтр за описом.
- **Чорний список ONU.** На сторінці OLT з'явилась вкладка з чорним списком ONU (та ознакою, чи він увімкнений), а на дешборді — віджет **«Чорний список ONU»**. Підтримуються C-Data EPON (за MAC) та C-Data FD16xxV3 GPON (за серійним номером); список оновлюється за розкладом.
- **Реєстрація ONU:**
    - ZTE C600 — для незареєстрованих ONU показується режим швидкості (GPON / XG-PON / XGS-PON);
    - BDcom GP3600 — виправлено реєстрацію ONU (помилка `Error find interface by ident`);
    - C-Data FD16xxV3 — виправлено формат серійного номера, через який реєстрація завершувалась помилкою розбору.
- **Huawei MA56xx/MA58xx:** надійніше видалення ONT — підтримуються обидва варіанти діалогу підтвердження різних прошивок; виправлено збій списку серійних номерів для ONT з порожнім серійником; виправлено LLDP та консольні команди (також для BDcom).
- **BDcom:** рівень RX з боку OLT тепер збирається при масовому опитуванні, опитуються лише ONU онлайн, нульове значення показується як порожнє; виправлено порожні або «биті» назви виробника/моделі ONU.
- Виправлено відображення діагностики кабелю.

### DHCP Snooping 🔎
- На сторінках комутаторів, OLT та ONU з'явилась картка **DHCP Snooping** з таблицею прив'язок MAC / IP / VLAN / порт / час оренди.
- **D-Link** (DES-3200, DES-30xx, DES-1228/ME, DGS-3000, DGS-3100, DGS-3120, DGS-3420) — таблиця прив'язок та режим DHCP relay.
- **BDcom EPON/GPON** (зокрема P3608B, GP3600) — прив'язки читаються по SNMP з резервом через консоль і точно зіставляються з конкретною ONU; фільтр за портом включає його ONU.
- **C-Data FD-EPON** — виправлено роботу на нових прошивках (стара команда більше не підтримується), прив'язки зіставляються з ONU.
- **C-Data FD11xx, FD16xxV3, FD17xxV3** — виправлено зсув полів у таблиці, додано номер ONU та фільтр за ONU.

### Робота з обладнанням 🛠️
- **SSH:** додано сучасні алгоритми ключів та обміну ключами (ssh-ed25519, rsa-sha2-256/512, curve25519-sha256 тощо) — WildcoreDMS підключається до нових прошивок і пристроїв, що відмовляються від застарілого ssh-rsa/SHA1. Старі алгоритми також підтримуються.
- Вимкнені пристрої більше не опитуються фоновими задачами та не потрапляють в автотопологію.
- У списку керування пристроями з'явилась колонка статусу (увімкнено/вимкнено) з фільтром і сортуванням.

### Макроси ⚡
- Вікно запуску макросу відкривається миттєво з індикатором завантаження; кнопки запуску активні лише після завантаження змінних; форми параметрів більше не ламаються через відсутні варіанти.
- Випадні списки параметрів коректно позиціонуються всередині модальних вікон.
- Попередній перегляд шаблону реєстрації ONU більше не показує застарілий результат.
