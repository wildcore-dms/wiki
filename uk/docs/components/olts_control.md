# Компонент «Керування OLT» (olts_control)

!!! abstract "Огляд"

    Додає **дії з ONU та портами OLT**: перезавантаження, вимкнення, видалення, скидання ONU, зміна опису, керування UNI-портами та фізичними портами. Працює разом з компонентом [OLT](./olts.md).

## Що дає

- Кнопки дій на [сторінці ONU](../system/onu.md#actions): «Перезавантаження ONT», «Видалити», «Скинути», «Вимкнути/Включити ONT»
- Редагування опису ONU та PON-порту
- Перемикач адмін. стану UNI-портів ONU
- «Конфігурування порта» та «Скинути порт» у вкладці «Фіз. інтерфейси» [OLT](../system/olt.md)

## Як працює

Кожна дія виконується командою на OLT — по SNMP або через консоль, залежно від моделі. Якщо модель не підтримує дію, кнопка не показується.

Перед небезпечними діями (перезавантаження, видалення, скидання, вимкнення) запитується підтвердження.

Після виконання дані ONU/порту оновлюються з обладнання, а дія записується в **журнал дій** (хто, коли, що зробив) — `Логи > Дії`.

Кнопки та перемикачі видно лише користувачам з відповідним правом — так монтажнику можна дозволити перезавантаження ONU, але заборонити видалення.

## Права

| Право | Що дозволяє |
|---|---|
| **Скасування реєстрації ONU** | Видалення ONU |
| **Перезавантаження ONU** | Перезавантаження |
| **Очищення лічильників ONU** | Скидання лічильників |
| **Скидання налаштувань ONU** | Скидання ONU |
| **Увімкнення / вимкнення ONU** | Вимкнення/увімкнення ONU |
| **Редагування опису ONU** | Зміна опису |
| **Керування фізичними портами** | Налаштування та скидання фізичних/PON-портів |
| **Керування UNI-портами на ONU** | Увімкнення/вимкнення портів ONU |

!!! note
    Права компонента **не надаються** за замовчуванням — видайте їх потрібним [ролям](../management/roles.md).

## Увімкнення

Компонент вмикається в `Конфігурація > Конфігурація системи` → вкладка «Компоненти» або командою:

```shell
sudo wca component:control olts_control enable
```
