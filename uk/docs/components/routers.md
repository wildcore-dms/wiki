# Компонент «Маршрутизатори» (routers)

!!! abstract "Огляд"

    Робота з L3-обладнанням (маршрутизатори, L3-комутатори): порти, таблиці ARP та FDB усього пристрою, прямі маршрути, VLAN.

## Що дає

- Вкладки «Порти», «ARPs», «FDB», «Прямые маршруты», «Влани» — [L3-обладнання](../system/switches.md#l3)
- Сторінку порту L3-пристрою

## Як працює

Дані отримуються по SNMP: порти, лічильники, таблиці ARP та FDB, прямі маршрути. [Опитувач](../system/poller.md) збирає ARP-таблиці фоново — вони використовуються також для пошуку абонента за IP ([Пошук пристроїв](./search_device.md)).

## Права

| Право | Що дозволяє |
|---|---|
| **Router info** | Перегляд L3-обладнання |

## Увімкнення

Компонент вмикається в `Конфігурація > Конфігурація системи` → вкладка «Компоненти» або командою:

```shell
sudo wca component:control routers enable
```
