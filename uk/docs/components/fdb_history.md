# Компонент «Історія FDB» (fdb_history)

!!! abstract "Огляд"

    Зберігає історію таблиць MAC-адрес (FDB): на якому порту чи ONU і в який час була кожна MAC-адреса. Дозволяє знайти, де абонент був підключений раніше, або відстежити переїзд обладнання.

## Що дає

- Картку **«FDB історія»** на сторінках порту та [ONU](../system/onu.md) — [Сторінка порту або ONU](../system/device-page.md#interface)
- Пошук за MAC в історії (глобальний пошук, API)
- Налаштування **«Зберігати FDB в історію»** для окремого інтерфейсу (картка «Інформація про зберігання»)

## Як працює

[Опитувач](../system/poller.md) періодично зчитує таблиці FDB з комутаторів та OLT (інтервал опитування `fdb_table` задається в моделі/пристрої).

Для кожної MAC-адреси зберігається інтерфейс, VLAN, час першої та останньої появи. Поки MAC присутній на порту — запис позначено «активно зараз»; коли зникає — фіксується час останньої появи.

Збереження можна вимкнути для окремого інтерфейсу (картка «Інформація про зберігання» → «Зберігати FDB в історію») — історія цього інтерфейсу буде очищена.

## Права

| Право | Що дозволяє |
|---|---|
| **Історія за інтерфейсом** | Перегляд історії на порту/ONU |
| **Пошук в історії FDB** | Пошук MAC по всій історії |

!!! note
    Для аплінків та транкових портів збереження FDB варто вимкнути — там тисячі MAC-адрес, які не несуть корисної інформації.

## Увімкнення

Компонент вмикається в `Конфігурація > Конфігурація системи` → вкладка «Компоненти» або командою:

```shell
sudo wca component:control fdb_history enable
```
