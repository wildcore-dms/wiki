# Компонент «OLT» (olts)

!!! abstract "Огляд"

    Базовий компонент для роботи з OLT: сторінка OLT, дерево ONU, фізичні та PON-порти, сторінка ONU, DHCP Snooping та чорний список ONU. Дає лише **перегляд** — дії з ONU та портами додає компонент [Керування OLT](./olts_control.md).

## Що дає

- Сторінку OLT з вкладками «Дерево ONT», «Фіз. інтерфейси», «DHCP Snooping», «Блеклист ОНУ» — [Робота з OLT](../system/olt.md)
- Сторінки PON-порту, фізичного порту та [ONU](../system/onu.md)
- [DHCP Snooping](../system/dhcp-snooping.md) та [чорний список ONU](../system/onu-blacklist.md) (зчитування за розкладом — `wca olts:get-onts-blacklist`)
- Фонове опитування ONU: статуси, сигнали, серійні номери, описи

## Як працює

Дані з OLT отримуються по **SNMP**, а те, що недоступне по SNMP (частина даних ONU, DHCP Snooping на деяких моделях), — через **консоль** (Telnet/SSH). Облікові дані — з [доступу](../management/device-access.md) пристрою.

**Фоново** [опитувач](../system/poller.md) за розкладом збирає з кожного OLT: системну інформацію та ресурси (CPU/RAM/температура), список інтерфейсів і їх стан, ідентифікатори ONU (серійні номери/MAC), рівні сигналу, лічильники трафіку та помилок, таблицю FDB, завантаженість PON-портів, дані виробника ONU. Інтервали задаються для моделі або пристрою.

Зібрані дані потрапляють у **кеш** (сторінки відкриваються швидко), в **історію метрик** (графіки, аналітика, [події](./events.md)) та в **історію станів** (таблиця аптайму, причини відключень).

При відкритті сторінки ONU частина даних (статус, сигнал, UNI-порти, FDB, конфігурація) запитується з OLT **напряму** або береться з кешу — джерело видно в блоці «Виклик пристрою». Кнопка «Оновити» примусово опитує OLT.

Задача планувальника `olts:get-onts-blacklist` кожні 10 хвилин зчитує чорні списки ONU з усіх OLT.

## Права

| Право | Що дозволяє |
|---|---|
| **Інформація з OLT** | Перегляд OLT, портів та ONU |

## Увімкнення

Компонент вмикається в `Конфігурація > Конфігурація системи` → вкладка «Компоненти» або командою:

```shell
sudo wca component:control olts enable
```
