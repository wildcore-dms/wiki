# Компонент «Керування комутаторами» (switches_control)

!!! abstract "Огляд"

    Додає **дії з комутаторами та L3-обладнанням**: перезавантаження, збереження конфігурації, очищення лічильників, зміна опису, стану та швидкості порту, керування VLAN на портах.

## Що дає

- Кнопки «Перезавантажте пристрій», «Очистити показники», «Зберегти конфігурацію на пристрої» — [Комутатори](../system/switches.md#device-actions)
- «Змінити порт» (адмін. стан, швидкість) та зміна опису на сторінці порту
- Вкладку «Влани» з керуванням VLAN на портах

## Як працює

Команди виконуються на обладнанні по SNMP (запис через RW community з [доступу](../management/device-access.md)) або через консоль — залежно від моделі. Для дій по SNMP у доступі обов'язково має бути вказано **RW community**.

Перед перезавантаженням та зміною стану порту запитується підтвердження; після дії дані порту оновлюються з обладнання.

Усі дії записуються в **журнал дій** — `Логи > Дії`.

Зміни не зберігаються в конфігурації комутатора автоматично — для цього є кнопка «Зберегти конфігурацію на пристрої».

## Права

| Право | Що дозволяє |
|---|---|
| **Перезавантаження пристрою** | Перезавантаження |
| **Збереження конфігурації комутатора** | Запис конфігурації |
| **Очищення лічильників** | Скидання лічильників |
| **Зміна опису порту** | Опис порту |
| **Зміна адміністративного стану порту** | Увімкнення/вимкнення порту |
| **Зміна швидкості порту** | Швидкість/дуплекс |
| **Керування VLAN на портах** | Вкладка «Влани» |

!!! note
    Права компонента **не надаються** за замовчуванням — видайте їх потрібним [ролям](../management/roles.md).

## Увімкнення

Компонент вмикається в `Конфігурація > Конфігурація системи` → вкладка «Компоненти» або командою:

```shell
sudo wca component:control switches_control enable
```
