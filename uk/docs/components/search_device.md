# Компонент «Пошук пристроїв» (search_device)

!!! abstract "Огляд"

    API для пошуку, де в мережі знаходиться абонент: за MAC-адресою (у таблицях FDB обладнання та історії) або за IP (через ARP маршрутизаторів з визначенням порту за FDB). Використовується білінгами та зовнішніми системами.

## Як працює

**Пошук за MAC**: MAC шукається в таблицях FDB обладнання (запит у реальному часі) та/або в [історії FDB](./fdb_history.md) — джерела задає `SEARCH_DEVICE_SOURCES`. Транкові порти можна ігнорувати, щоб отримати саме порт абонента.

**Пошук за IP**: IP шукається в ARP-таблицях маршрутизаторів; варіант `search-ip-with-fdb` додатково знаходить MAC у FDB комутаторів і повертає порт, до якого підключено абонента.

Можна обмежити пошук переліком пристроїв; інакше опитуються всі пристрої паралельно (`SEARCH_DEVICE_REQUEST_CONCURRENCY`).

## Методи API

| Метод | Опис |
|---|---|
| `GET /api/v1/component/search_device/search-mac` | Пошук MAC у FDB пристроїв та/або в історії FDB |
| `GET /api/v1/component/search_device/search-ip` | Пошук IP в ARP-таблицях маршрутизаторів |
| `GET /api/v1/component/search_device/search-ip-with-fdb` | Пошук IP через ARP з визначенням порту комутатора за FDB |

## Налаштування

Джерела пошуку, паралельність, ігнорування транкових портів — параметри `SEARCH_DEVICE_*` у [Налаштуваннях системи](../installation-and-updating/env-configuration.md#web).

## Права

| Право | Що дозволяє |
|---|---|
| **Пошук за MAC-адресою** | search-mac |
| **Пошук за IP-адресою** | search-ip |
| **Пошук ARP через FDB (пошук портів)** | search-ip-with-fdb |

## Увімкнення

Компонент вмикається в `Конфігурація > Конфігурація системи` → вкладка «Компоненти» або командою:

```shell
sudo wca component:control search_device enable
```
