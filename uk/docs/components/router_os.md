# Компонент «Mikrotik RouterOS» (router_os)

!!! abstract "Огляд"

    Робота з маршрутизаторами Mikrotik через API RouterOS: інтерфейси, address lists, ARP, DHCP-сервери та оренди, прості черги, BGP-сесії.

## Що дає

- Окрему сторінку RouterOS-пристрою — [Mikrotik RouterOS](../system/routeros.md)
- Опитування трафіку інтерфейсів та BGP-сесій

## Як працює

Дані отримуються через **API RouterOS** (порт 8728 за замовчуванням) з логіном і паролем з доступу пристрою. Вкладки запитують маршрутизатор при відкритті; трафік інтерфейсів та BGP-сесії [опитувач](../system/poller.md) збирає фоново для графіків та подій.

## Права

| Право | Що дозволяє |
|---|---|
| **Інформація про RouterOS** | Перегляд даних RouterOS |

## Увімкнення

Компонент вмикається в `Конфігурація > Конфігурація системи` → вкладка «Компоненти» або командою:

```shell
sudo wca component:control router_os enable
```
